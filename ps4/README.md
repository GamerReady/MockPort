# MockPort PS4 build pipeline (OpenOrbis)

`.github/workflows/ps4-build.yml` downloads the open-source
[OpenOrbis PS4 Toolchain](https://github.com/OpenOrbis/OpenOrbis-PS4-Toolchain)
(pinned to `OO_VERSION`), builds the shell app in `ps4/app`, signs it into
`eboot.bin` and packs a `.pkg` for a jailbroken PS4. Assets (`param.sfo`,
`icon0.png`, `pic0.png`) are generated by `ps4/tools/gen_assets.py`.

Local build (Linux): set `OO_PS4_TOOLCHAIN` to the toolchain root, install
`clang lld python3` and a .NET runtime, then run `bash ps4/tools/build_pkg.sh`.
The package ends up in `ps4/build/pkg/`.

The shell app only writes `/data/mockport/boot.log` and exits; it does not run
the Mocktail runtime. The second CI step (`probe_port_sources.sh`) syntax-checks
the PS4-specific Mocktail sources and Mbed TLS against OpenOrbis and writes a
report, without failing the job. Use it to see what still blocks a real build.
